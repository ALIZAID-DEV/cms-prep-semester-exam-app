# CMS Prep — Programming Fundamentals Roadmap

## Course focus

Programming Fundamentals is a 4-credit BSCS course with theory and practical work. CMS Prep will teach it through problem-solving logic first, then algorithms, flowcharts, C++ examples, and lab-style practice.

## Three comprehensive video sections

### Video 1 — Problem Solving, Algorithms, and Flowcharts
Computational thinking, problem definition, input/process/output, step-by-step algorithms, flowchart symbols, decision-making, and examples such as adding two numbers and finding the largest value.

### Video 2 — Programming Basics and Control Flow
Programming languages, compiler and linker, variables, data types, input/output, arithmetic/comparison/logical operators, conditional statements, and loops.

### Video 3 — Arrays, Functions, Memory, Files, and Debugging
Lists and arrays, multi-dimensional arrays, modular programming, functions, stack rolling/unrolling, strings, pointers/references, static/dynamic memory, file I/O, and basic debugging.

## Practical exam priorities

Students should practice writing algorithms and flowcharts before code. Then they should implement input/output programs, arithmetic calculations, if/else decisions, loops, arrays, functions, strings, and simple file operations in the language used by their lab instructor.

## Exam preparation rule

For every programming question, CMS Prep will show the problem statement, logic in Roman Urdu + English, algorithm, flowchart idea, code, sample input/output, and common mistakes. This approach prepares the student for both theory and practical marks.

## Source alignment

The course outline states that the course covers problem-solving steps, algorithm design, programming constructs, and implementation. It also identifies theory and practical assessment components, so the CMS Prep package will include both conceptual questions and code-writing practice.
