Course Introduction
This course provides fundamental concepts of programming to freshmen. The course is a pre-requisite
to many other courses including Object-Oriented Programming and Data Structures. Therefore,
students are strongly advised to cover all contents and try to achieve Course Learning Outcomes
(CLOs) to the maximum possible level.

The course may be taught as language independent. However, it is up to the university to choose any
language for the practical/lab purpose, but that must be latest and market oriented. Students will learn
problem-solving techniques, algorithm design, and implementation using modern programming
constructs.

                                    COURSE OUTLINE
The following is an abstract outline of major topics to be covered throughout the semester. Please note
that this is a high-level overview - each topic will include various subtopics, practical examples, and
additional concepts as explained during lectures and lab sessions:

          1. Introduction to problem solving and computational thinking
          2. Brief review of Von-Neumann architecture
          3. Introduction to programming and programming languages
          4. Role of compiler and linker
          5. Introduction to algorithms and flowcharts
          6. Basic data types and variables
          7. Input/output constructs
          8. Arithmetic, comparison and logical operators
          9. Conditional statements and execution flow for conditional statements
          10. Repetitive statements and execution flow for repetitive statements (loops)
          11. Lists and their memory organization
          12. Multi-dimensional lists/arrays
          13. Introduction to modular programming
          14. Function definition and calling
          15. Stack rolling and unrolling
          16. String and string operations
          17. Pointers/references
          18. Static and dynamic memory allocation
          19. File I/O operations
          20. Introduction to basic debugging techniques

Teaching Methodology
      •   Theory Classes: Lectures, discussions, problem-solving sessions
      •   Lab Sessions: Hands-on programming practice, guided exercises, mini-projects
      •   Assessment Methods: Written exams, programming assignments, quizzes, presentations
      •   Learning Approach: Progressive learning from basic concepts to complex problem-solving


Lab Requirements
Students must:
   • Attend all scheduled lab sessions
   • Complete assigned programming exercises
   • Submit lab reports/code as required
   • Maintain a programming portfolio
   • Demonstrate working programs to instructor


Important Notes for Students
      •   This course is foundational for your computer science education

      •   Start assignments early to avoid last-minute issues
