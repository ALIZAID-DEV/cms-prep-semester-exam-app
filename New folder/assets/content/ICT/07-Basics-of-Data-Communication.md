Lecture 6: Basics of Data Communication
🔹 Key Terminologies
    Data: Raw facts and figures such as text, numbers, images, audio, and video.
     Example: A list of student names and marks before processing is data.
    Data Communication: Transfer of data electronically between devices.
     Example: Sending an email from a laptop to a smartphone.
    Data Transmission: Sending data via wired or wireless medium.
     Example: Streaming a YouTube video over Wi-Fi.
    Analog Signals: Continuous waves that vary with time, prone to interference.
     Example: Human voice in a phone call, represented by sine waves.
    Digital Signals: Discrete binary values (0s and 1s), less prone to noise.
     Example: Data stored on a USB drive, represented by square waves.
    Data Rate (Bit Rate): Number of bits transmitted per second.
     Example: A 100 Mbps internet connection transfers 100 million bits per second.
    Baud Rate: Number of signal units per second; one signal may represent multiple
     bits. Example: A modem transmitting at 1200 baud means 1200 signal changes
     per second.
    Signal-to-Noise Ratio (SNR): Ratio of signal power to noise power, measured
     in decibels.
     Example: A high SNR in a Wi-Fi connection means clearer data transmission.

🔹 Components of a Communication System
 1. Message – The information to be sent (text, audio, video).
    Example: A WhatsApp message containing text and emojis.
 2. Sender – Device generating the message.
    Example: A computer sending an email.
 3. Receiver – Device receiving the message.
    Example: A smartphone receiving the email.
 4. Medium – Path for transmission (wired or wireless).
    Example: Fiber optic cable for internet, or radio waves for mobile phones.
 5. Protocol – Rules for communication.
    Example: TCP/IP protocol used in the internet.
🔹 Properties of a Good Communication System
    Delivery – Data must reach the correct destination. Example: An online banking
     transaction must reach the correct account.
    Accuracy – Data must be error-free. Example: A corrupted file download is
     useless.
    Timeliness – Data must arrive on time. Example: Live video streaming must
     deliver frames without delay.

🔹 Transmission Media
    Guided (Wired):
       o Twisted Pair:
              UTP – Cheap, used in telephone lines.
              STP – Shielded, used in Ethernet networks.
       o Coaxial Cable: Used in cable TV connections.
       o Fiber Optic: Uses light, very high speed, used in modern internet
          backbones.
    Unguided (Wireless):
       o Radio Waves: Omnidirectional, used in FM/AM radios, cordless phones.
       o Microwaves: Line-of-sight, used in mobile towers and satellite TV.
       o Infrared: Short-range, used in TV remote controls and wireless LANs.




🔹 Transmission Impairments
    Attenuation: Loss of signal strength over distance.
     Example: Wi-Fi signal weakens as you move farther from the router.
    Distortion: Signal shape changes due to varying speeds of components.
     Example: Audio distortion in long-distance phone calls.
    Noise: Unwanted signals interfering with transmission.
     Example: Crosstalk in telephone lines or static in radio signals.
