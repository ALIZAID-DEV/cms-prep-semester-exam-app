📘 Software Overview
Software is defined as “a collection of programs that tell the computer what to do”. Unlike
hardware, which is the physical part of the computer, software is intangible but crucial for
functionality. Peter Norton emphasizes that without software, hardware is useless.


🖥️ Operating Systems (OS)
      Definition: An operating system is system software that manages computer hardware and
       provides services for application software.
      Functions:
          o Controls input and output devices.
          o Manages files and storage.
          o Allocates memory and processor time.
          o Provides a user interface (command-line or graphical).
      Examples: Microsoft Windows, Linux, macOS.
      Key Point for Students: The OS acts as a bridge between the user and the hardware,
       ensuring efficient and secure operation.


💻 Programming Software
      Definition: Tools used by programmers to create, test, and maintain other software.
      Components:
           o Compilers – translate high-level code into machine language.
           o Interpreters – execute code line by line.
           o Debuggers – help identify and fix errors.
      Languages Mentioned in the Book: C, C++, Java, and newer scripting languages.
      Key Point for Students: Programming software is essential for developing both operating
       systems and applications, making it the backbone of computer science education.


📂 Application Software
      Definition: Programs designed to perform specific tasks for the user.
      Categories:
          o Productivity Software: Word processors, spreadsheets, presentation tools.
          o Specialized Applications: CAD software, statistical analysis tools.
          o Entertainment & Multimedia: Games, media players.
      Examples: Microsoft Office, Adobe Photoshop, AutoCAD.
      Key Point for Students: Application software is what most users interact with daily, making
       computers useful for education, business, and personal tasks.
