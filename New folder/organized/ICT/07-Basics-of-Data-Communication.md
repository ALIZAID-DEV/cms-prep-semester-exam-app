- Transmission media: Guided (Twisted Pair — UTP/STP, Coaxial, Fiber Optic) aur Unguided (Radio Waves, Microwaves, Infrared).  
- Transmission impairments: Attenuation (signal loss over distance), Distortion (shape change due to different component speeds), Noise (unwanted interfering signals). Examples diye gaye (Wi‑Fi weakening, audio distortion, crosstalk).

## Key Exam Points
- Define Data vs Information; give an example for each.  
- Distinguish Analog Signal and Digital Signal; know typical examples (voice vs USB data).  
- Bit Rate (bits/sec) vs Baud Rate (signal changes/sec) — understand that baud *can* represent multiple bits.  
- SNR measured in decibels (dB) — higher SNR = clearer transmission.  
- Communication system components: Message, Sender, Receiver, Medium, Protocol — know examples.  
- Properties to test: Delivery, Accuracy, Timeliness — map common failures (corruption → Accuracy; late packets → Timeliness; wrong recipient → Delivery).  
- Transmission media categories: Guided (Twisted Pair: UTP/STP, Coaxial, Fiber Optic) and Unguided (Radio, Microwave, Infrared) — know common uses (telephone lines, cable TV, internet backbone, radio, mobile towers, TV remotes).  
- Impairments: Attenuation (use amplifiers/repeaters), Distortion (equalization), Noise (shielding, error detection/correction).  
- Typical exam MCQs will ask definitions, examples, unit measurements (e.g., Mbps as megabits/sec, SNR in dB), and mapping examples to concepts.

## MCQs
1. Which term describes continuous waves that vary with time and are prone to interference?  
   a) Digital Signal  
   b) Data Rate  
   c) Analog Signal  
   d) Baud Rate  
   Correct answer: c) Analog Signal

2. What does Baud Rate measure?  
   a) Number of bits transmitted per second  
   b) Number of signal changes per second  
   c) Ratio of signal power to noise power  
   d) Number of protocols used per second  
   Correct answer: b) Number of signal changes per second

3. Which transmission medium is commonly used for modern internet backbones?  
   a) Twisted Pair  
   b) Coaxial Cable  
   c) Fiber Optic  
   d) Infrared  
   Correct answer: c) Fiber Optic

4. Which impairment is characterized by loss of signal strength over distance?  
   a) Noise  
   b) Distortion  
   c) Attenuation  
   d) Protocol  
   Correct answer: c) Attenuation

5. Signal-to-Noise Ratio (SNR) is typically measured in:  
   a) Hertz  
   b) Bits  
   c) Decibels  
   d) Volts  
   Correct answer: c) Decibels
