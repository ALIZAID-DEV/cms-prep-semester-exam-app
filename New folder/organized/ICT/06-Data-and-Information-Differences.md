## Lecture Explanation
Yeh lecture ek concise comparison/summary hai jo chaar important pairs ko differentiate karta hai. Roman Urdu + English mein short explanations:

- Data vs Information  
  Data raw facts hote hain — just numbers/symbols (e.g., "25, 30, 35"). Information wohi data jab process karke context aur meaning diya jata hai (e.g., "Average age of students is 30"). Data khud mein unorganized aur meaningless ho sakta hai; Information processed, organized aur useful hoti hai. Information always depends on Data.

- RAM vs ROM  
  RAM (Random Access Memory) temporary memory hai jo currently use ho rahi values store karti hai; volatile — power off karte hi data loss hota hai. RAM ko CPU easily read/write kar sakta hai; bahut fast hoti hai. ROM (Read-Only Memory) permanent memory hai jo firmware/boot instructions store karti hai; non-volatile — power off ke baad bhi content rehta hai; usually read-only aur slower compared to RAM.

- Software vs Hardware  
  Software instructions/programs hain jo hardware ko batate hain kya karna hai — intangible aur easily updateable (apps, OS). Hardware physical components hain (CPU, keyboard, monitor) — tangible aur change karne ke liye physical replacement chahiye. Software ko run karne ke liye hardware chahiye; hardware ko useful banane ke liye software chahiye.

- CPU vs GPU  
  CPU (Central Processing Unit) general-purpose processor hai with a few powerful cores for sequential/low-latency tasks — system management, OS, applications. GPU (Graphics Processing Unit) specialized hai with thousands of smaller cores for parallel/high-throughput tasks — graphics rendering, machine learning, simulations. CPU latency-optimized; GPU throughput-optimized.

## Key Exam Points
- Data vs Information:  
  - Data = raw facts; Information = processed, meaningful.  
  - Information cannot exist without Data; Data can exist independently.

- RAM vs ROM:  
  - RAM = volatile, temporary, read/write, high speed.  
  - ROM = non-volatile, permanent firmware/boot storage, typically read-only.

- Software vs Hardware:  
  - Software = intangible, updateable, needs hardware.  
  - Hardware = tangible, physical, needs software to be useful.

- CPU vs GPU:  
  - CPU = few powerful cores, optimized for latency/sequential tasks.  
  - GPU = many small cores, optimized for parallel/throughput tasks.
