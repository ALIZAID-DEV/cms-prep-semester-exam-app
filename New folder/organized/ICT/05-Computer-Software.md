## Lecture Explanation
Software ko define kiya gaya hai as “a collection of programs that tell the computer what to do”. Hardware physical cheez hai; software intangible hai magar bina software hardware useless ho jata hai — jaise Peter Norton bhi emphasize karte hain. 

Operating Systems (OS): OS system software hai jo computer hardware ko manage karta hai aur application software ko services provide karta hai. OS ka role ek bridge jaisa hai between user and hardware. Functions include: control of input/output devices, file and storage management, memory and processor time allocation, aur user interface (command-line ya graphical). Examples: Microsoft Windows, Linux, macOS.

Programming Software: Yeh tools hain jo programmers use karte hain software create, test, aur maintain karne ke liye. Iske components: Compilers (translate high-level code into machine language), Interpreters (execute code line by line), Debuggers (identify and fix errors). Languages mentioned: C, C++, Java, aur newer scripting languages. Programming software operating systems aur applications dono develop karne mein essential hai.

Application Software: Programs jo specific user tasks perform karte hain. Categories: Productivity software (word processors, spreadsheets, presentations), Specialized applications (CAD, statistical analysis tools), Entertainment & Multimedia (games, media players). Examples: Microsoft Office, Adobe Photoshop, AutoCAD. Yeh woh software hai jisse aam users rozana interact karte hain.

Comparison (short): System software (Operating Systems) hardware manage karta hai aur programming software developers ko coding tools deta hai; application software end-user tasks ke liye hota hai.

## Key Exam Points
- Software = collection of programs; bina software hardware kaam nahi karta.  
- OS = system software jo hardware ko manage karta hai aur user/application ke beech bridge hai.  
- OS functions: device control, file/storage management, memory & CPU scheduling, user interface.  
- Examples of OS: Windows, Linux (open-source, server use), macOS.  
- Programming software includes: compilers (whole-program translation), interpreters (line-by-line execution), debuggers (error finding/fixing), IDEs (e.g., Visual Studio).  
- Common programming languages referenced: C, C++, Java, plus scripting languages.  
- Application software categories: productivity, specialized (e.g., AutoCAD), entertainment (games).  
- Distinction: System software manages hardware; application software serves user needs.  
- Important fact for exams: Kernel = core part of OS that interacts with hardware.  
- Practical tip: Know examples and class of each software type (identify whether given example is system, programming, or application).
