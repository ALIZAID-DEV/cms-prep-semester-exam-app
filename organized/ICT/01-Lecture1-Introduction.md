Lecture Explanation
Ye lecture slides ek introductory overview hain of the ICT course aur basic computer concepts. Course ka naam hai "Introduction to Information and Communication Technologies (ICT)" — credit hours 3 (2+1) aur koi pre-requisite nahi hai. Course outline mein topics jaise Basic Definitions & Concepts, Hardware (Computer Systems & Components), Storage Devices, Number Systems, Software (Operating Systems, Programming, Application Software), Databases, Networks, Internet services (browsers, email, e-commerce), IT Security, Project week aur Review week diye gaye hain.

Definition of computer: A computer ek electronic device hai jo user ka input (data) process karta hai, store karta hai aur output (information) produce ya retrieve karta hai. Processing instructions ko computer program kehte hain.

Characteristics of a computer (Roman Urdu + English):
- Speed: Computers bohat high speeds par kaam karte hain; processing speed ko MegaHertz (MHz) ya GigaHertz (GHz) mein measure kiya jata hai.
- Accuracy: Large data ko precise and exact process karte hain; modern systems kuch errors detect/handle kar sakte hain.
- Diligence: Repeat tasks bina thakay kar sakte hain (industrial robotics, assembly lines).
- Storage: Large amounts of data permanently store kar sakte hain — text, graphics, audio, video.
- Processing: Arithmetic (add, sub, mul, div) aur logical operations perform karte hain.
- Communication: Computers modem ya other communication devices se connect hoke data/instructions share kar sakte hain; connected computers network banate hain.
- Versatility: Different types of input (text, images, sound, voice) ke saath computation kar sakte hain.
- Automation: Programs ke through automatic routines bina manual supervision ke chal sakte hain.

Basic Parts of a computer:
- System Unit: Yeh housing hota hai for the Central Processing Unit (CPU) aur drives (storage devices) jo data read/write karte hain.
- Peripheral Devices: External devices jo system unit se interface cables aur ports ke zariye connect hote hain. Examples: Keyboard (data entry), Mouse (pointing device, execute commands by clicking icons), Monitor (display device to "monitor" what is happening).
