Lecture Explanation
Computer hardware ka basic farq yeh hai ke "hardware" woh physical parts hain jo aap dekh aur chhoo sakte hain (CPU, motherboard, RAM, graphics card, casing), jabke "software" woh programs hain jo in hardware par chalti hain. System Unit main components mein motherboard, CPU (microprocessor), RAM, ROM aur casing shamil hain. Motherboard ek central board hai jo sare components ko connect karta hai — isay aksar "nervous system" kehte hain. 

CPU ya microprocessor ko computer ka "brain" samjha jata hai; iske andar ALU (Arithmetic and Logical Unit) calculations karte hain, CU (Control Unit) data transfer aur operations ko control karti hai, clock instruction execution ke liye timing pulses deti hai, registers temporary processing storage hain, aur cache ek fast intermediate memory hoti hai (internal/external). Components ko connect karne ke liye different buses use hoti hain: Control Bus (commands), Data Bus (data transfer), Address Bus (memory locations specify karna).

Input devices mein text entry (keyboard), pointing devices (mouse, joystick, trackball, trackpad), image scanners jese OMR, OBR, OCR, aur audio input (microphones, voice recognition), touch screens, MICR, magnetic strip readers aate hain. Output devices do tarah ke hote hain: soft copy (monitor — CRT ya flat panel, projectors, speakers) aur hard copy (printers — impact, non-impact; plotters for large images). 

Storage primary aur secondary mein divide hota hai: Primary storage mein RAM (volatile) aur ROM (non-volatile / permanent) shamil hain. Secondary storage mein hard disk, CD/DVD, SD card, USB flash drives etc. Basic operations of a computer chaar hain: Input (data entry), Processing (CPU processing), Storage (RAM/ROM/hard disk), Output (display/printer/speakers).

Key Exam Points
- Hardware vs Software: Hardware = visible/tangible parts; Software = programs that run on hardware.
- System Unit: Motherboard connects CPU, RAM, ROM, expansion slots, ports and buses.
- CPU components: ALU (arithmetic & logical), CU (control/coordination), Clock (timing), Registers (temporary storage), Cache (fast intermediate memory).
- Buses: Control Bus = commands, Data Bus = data transfer, Address Bus = memory addresses.
- Input Devices: Keyboard (text), Mouse/trackpad/joystick (pointing), OCR/OMR/OBR (image/text scanning), MICR (cheque recognition).
- Output Devices: Monitor/projector/speakers = soft copy; Printers/plotters = hard copy.
- Storage: RAM is volatile; ROM stores permanent firmware/settings; Secondary storage used for long-term/permanent data.
- Basic operations: Input -> Processing -> Storage -> Output (processing converts input into meaningful output).

MCQs
1. Which component is responsible for arithmetic and logical operations?
   A) Control Unit
   B) ALU
   C) Cache
   D) Register
   Answer: B

2. Which bus carries memory addresses from the CPU?
   A) Data Bus
   B) Control Bus
   C) Address Bus
   D) System Bus
   Answer: C

3. Which of the following is considered primary storage?
   A) Hard disk
   B) USB flash drive
   C) RAM
   D) CD/DVD
   Answer: C

4. OCR stands for:
   A) Optical Code Reader
   B) Online Character Register
   C) Optical Character Recognition
   D) Output Control Register
   Answer: C

5. Which device provides permanent hard copy output?
   A) Monitor
   B) Speaker
   C) Printer
   D) Projector
   Answer: C
