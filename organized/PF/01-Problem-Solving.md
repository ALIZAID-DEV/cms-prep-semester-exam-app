Lecture Explanation
- Problem Solving kya hai? Problem Solving is the process of finding solutions to difficult or complex issues through systematic thinking and analysis. Roman Urdu: Masla hal karne ka structured tareeqa — samajhna, plan karna, execute karna, verify karna.
- Computational Thinking ka matlab: Problems ko aise structured aur logical tareeqay se solve karna ke ek computer ya insan easily steps follow kar sakay. (“Not thinking like a computer, but solving so computers can help.”)
- Four Pillars of Computational Thinking:
  - Decomposition (Breaking Down Problems): Bari problem ko chhoti manageable tasks mein divide karna. Example: Making biryani — wash rice, marinate meat, prepare masala, layer, dum. Programming example: student management system sub-tasks (add, delete, update, search, display).
  - Pattern Recognition (Finding Similarities): Repeated patterns ya similarities identify karna. Example: daily routine repeats; programming example: finding maximum — compare each value with current maximum and update.
  - Abstraction (Focus on Important Details): Unnecessary details ignore karna aur sirf relevant information rakhnay par focus. Example: ATM user ko internal machine workings ki zaroorat nahi; Programming example: cout<<"Hello World" — internal kaam hidden.
  - Algorithm Design (Step-by-Step Solution): Clear logical sequence of steps banana. Example: Making tea steps; programming example: check even/odd — input, divide by 2, check remainder, display.
- Problem Solving Steps (general): Understand → Plan → Execute → Verify. Roman Urdu: Pehle problem ko samjho (what exactly), phir possible solutions list karo, phir implement karo, phir result verify karo aur agar fail ho to doosra approach try karo.
- Why learn Computational Thinking: Better problem-solving skills, logical thinking, efficient solutions, error handling, useful across careers (IT, business, medicine, engineering).
- Applying CT for Exam Preparation: Use pillars to prepare — Decomposition (understand syllabus, collect notes, schedule, practice), Pattern Recognition (similar question types repeat), Abstraction (focus on important topics/formulas), Algorithm Design (7-day plan example: list topics, study 2/day, short notes, solve questions, revise day 6, past papers day 7).
- Application Example — Create a Calculator Program:
  - Decomposition: input two numbers, select operation, perform calculation, display result, handle errors.
  - Pattern Recognition: operations share same input-process-output structure.
  - Abstraction: user need not know internal memory/ binary calculations.
  - Algorithm Design: steps like input first number, input second number, input operation, perform operation, check division-by-zero, display result.
- Activities & Homework: Pattern recognition sequences, decomposition (plan a birthday party), algorithm writing (make a phone call). Homework: choose daily-life problem, apply all four pillars, write solution, be ready to discuss.

Key Exam Points
- Memorize the four pillars: Decomposition, Pattern Recognition, Abstraction, Algorithm Design.
- Know the four generic Problem Solving steps: Understand, Plan, Execute, Verify.
- Be able to give one real-life and one programming example for each pillar (e.g., biryani/student system for Decomposition).
- Be able to write a simple algorithm step-by-step (e.g., even/odd check, making tea, calculator flow including division-by-zero check).
- For exam prep questions: demonstrate how to use pillars to make a study plan (example: 7-day algorithm given in slides).
- Practice identifying patterns (series, repeated question types) and decomposing complex tasks into subtasks.
- Understand abstraction: explain what details to ignore (internal workings) vs what to keep (inputs/outputs).
- Implementation detail not required unless asked (focus on logical steps and error checks).
