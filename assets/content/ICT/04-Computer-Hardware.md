📘 Summary: Computer Hardware
1. Hardware vs. Software
      Hardware: Physical components of a computer (CPU, motherboard, memory, graphics card,
       sound card, casing).
      Software: Programs and applications that run on hardware.

2. System Unit
      Contains primary devices: motherboard, CPU, RAM, casing.
      Motherboard: Main board connecting all parts; includes CPU, slots, ports, buses, RAM,
       ROM, chipsets. Functions like a nervous system.
      CPU (Microprocessor): Brain of the computer; performs calculations at high speed.
       Components:
          o ALU:              Arithmetic and logical operations.
          o CU:               Controls data transfer and operations.
          o Clock:            Generates pulses for instruction execution.
          o Registers:        Temporary storage for processing data.
          o Cache:            Fast intermediate storage (internal/external).
      Buses: Electrical paths connecting components.
          o Control Bus: Carries Commands.
          o Data Bus:         Transfers data.
          o Address Bus: Carries Specifies memory locations.

3. Input Devices
      Text Entry: Keyboard.
      Pointing Devices: Mouse, joystick, trackball, track pad.
      Image Scanners: Optical Mark Recognition (OMR), Optical Barcode Reader (OBR) and
       Optical Character Recognition (OCR)
      Other Devices: Microphones (voice recognition), touch screens, MICR, magnetic strip
       readers.

4. Output Devices
      Soft Copy: Monitors (CRT, flat panel), projectors, speakers.
      Hard Copy: Printers (impact, non-impact), plotters.

5. Storage Devices
      Primary Storage:   RAM (volatile), ROM (permanent).
      Secondary Storage: Hard disk, CD/DVD, SD card, USB flash drive.

6. Basic Operations of a Computer
      Input: Data entry via keyboard, mouse, or network.
      Processing: CPU converts input into meaningful information.
      Storage: Data held in RAM, ROM, or hard disk.
      Output: Results displayed on monitor, speakers, or printer.

✅ In short: The document explains the distinction between hardware and software, details the
system unit and its components, categorizes input/output devices, differentiates primary and
secondary storage, and outlines the four basic operations of a computer (input, processing, storage,
output).
